# NYANTET — UI & UX Guidelines

## Design Philosophy
Target visual style:
- Notion (clean, calm, minimal)
- Linear (modern, premium)
- Apple (soft, spacious, polished)

The application should feel like a personal tool, NOT an admin dashboard.

## Design Principles

- Mobile-first
- Minimal UI
- Premium appearance
- Plenty of whitespace
- Fast interaction
- Consistent spacing (8px grid)

## Theme

Primary:
- #4F46E5

Background:
- #F8F8F7 (Light)
- #0F172A (Dark)

Surface:
- #FFFFFF / #1E293B

Income:
- Green

Expense:
- Red

Text:
- #111827

Border:
- #E5E7EB

## Typography

Font:
- Inter (preferred)
- Geist (alternative)

Avoid decorative fonts.

## Navigation

Mobile:
- Bottom Navigation (Home, Income, Add, History, Settings)

Desktop:
- Responsive layout.
- Do NOT use a permanent admin-style sidebar.

## Components

Cards:
- Rounded corners (16px)
- Soft shadow
- Minimal borders

Buttons:
- Rounded
- Large tap target
- Subtle hover animation

Inputs:
- Clean
- Minimal border
- Spacious padding

## Forms

Income:
- Amount
- Source (TEXT INPUT, not dropdown)
- Date

Expense:
- Amount
- Description
- Date

Avoid unnecessary dropdowns.

## Dashboard

Display:
- Current Balance
- Total Income
- Total Expense
- Recent Transactions

No excessive cards.

## UX

Target:
- Add transaction in under 10 seconds.
- Maximum 2 taps before entering data.
- Smooth 200–250ms transitions.

## Do

- Keep screens simple.
- Prioritize readability.
- Build an app that feels native on Android.

## Don't

- Don't look like an admin dashboard.
- Don't overuse gradients.
- Don't use excessive shadows.
- Don't add unnecessary controls.
